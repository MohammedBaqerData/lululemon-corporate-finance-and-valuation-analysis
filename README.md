# Lululemon — Corporate Finance & Valuation Analysis

An academic corporate finance project examining Lululemon Athletica Inc.’s investment decisions, working capital, financial risks, and valuation.

**Prepared by:** Mohammed Baqer  
**Tools:** Microsoft Excel  
**Company:** Lululemon Athletica Inc. (NASDAQ: LULU)

## Project Overview

This project combines financial analysis and Excel calculations to evaluate proposed investments, compare liquidity and operating efficiency with industry peers, and estimate company value using market multiples.

## Areas Covered

- **Capital budgeting:** Evaluated two proposed projects using NPV, IRR, payback period, discounted payback, profitability index, and annualized NPV.
- **Cost of capital:** Estimated WACC using financing assumptions and CAPM-based cost of equity.
- **Sensitivity analysis:** Examined how changes in discount rates affect project NPV.
- **Working capital:** Compared liquidity ratios, operating cycles, and cash conversion cycles with Nike, Adidas, and Puma.
- **Risk assessment:** Examined business, financial, operational, and external risks.
- **Valuation:** Applied P/E, EV/EBITDA, and P/B multiples to estimate share value and compare valuation methods.
